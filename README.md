## 🚀 Getting Started
Welcome to HashIndex! This application simplifies document indexing using advanced techniques that don't require vector search. In this guide, we will help you download and run HashIndex on your computer.

### 📋 System Requirements
Before you begin, make sure your system meets the following requirements:
- Operating System: Windows 10 or later, macOS Mojave or later
- RAM: At least 4 GB
- Storage: Minimum of 500 MB of free space

### 🌐 Features
HashIndex offers several features to enhance your document indexing experience:
- **LLM Optimization:** Built to index documents efficiently using language models.
- **User-Friendly Interface:** Simple navigation that anyone can use.
- **Quick Indexing:** Get results in minutes, even with large documents.
- **Support for Multiple Formats:** Index PDF, DOCX, TXT, and more.

### 📂 Installation Steps
1. **Run the Installer:** Double-click the downloaded file to start the installation.
2. **Follow On-Screen Prompts:** Accept the terms of service and choose your installation location.
3. **Complete the Installation:** Click 'Finish' when the setup is complete. You can now find HashIndex in your applications.

## 🎉 Using HashIndex
1. Open HashIndex from your applications menu or desktop shortcut.
2. Click on the “Index Document” button.
3. Select the document you want to index.
4. Choose your indexing settings, if applicable.
5. Click “Start Indexing.” The application will process your document and display the results.
